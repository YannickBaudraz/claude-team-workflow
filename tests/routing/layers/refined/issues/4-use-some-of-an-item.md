# Use some of an item

As a cook, I use some of an item, so the quantity goes down.

## Rules
- Using more than there is leaves zero and says so.

## Examples
- rice at 2kg, `pantry use rice 500g` leaves 1.5kg.

## Acceptance criteria
- [ ] Using part of an item lowers its quantity.
- [ ] Using more than there is leaves zero and prints a warning.
